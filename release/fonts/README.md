CascadiaMono.ttf is the unmodified variable Cascadia Mono font from
Microsoft Cascadia Code v2102.03 (Ubuntu/Debian package fonts-cascadia-code
2102.03-1). Its regular face is called `Cascadia Mono Roman` in GIMP.

Upstream: https://github.com/microsoft/cascadia-code/tree/v2102.03

The adjacent OFL.txt contains the upstream copyright and SIL Open Font
License. The font is used only to render the cart label's version number;
the game fonts are unchanged. The renderer explicitly adds this directory
to GIMP's font path, so a system font installation is unnecessary.
